Español

Qué es. HanDy Analitica es una herramienta privada del equipo del canal de YouTube HanDy. Analiza los datos del propio canal para decidir qué videos publicar. No es un servicio público ni se ofrece a terceros.

Qué datos usa. Con tu permiso, y siempre en solo lectura, accede mediante los Servicios de API de YouTube (YouTube Data API, YouTube Analytics API y YouTube Reporting API) a la información del canal autorizado: lista de videos y sus metadatos, estadísticas (vistas, tiempo de visualización, retención, suscriptores), ingresos estimados y fuentes de tráfico. No accede a tu correo, contraseñas, mensajes ni a otros servicios de Google.

Cómo se usa y dónde se guarda. Los datos se guardan solo en el computador del equipo del canal y se usan únicamente para analizar el rendimiento del canal y generar recomendaciones de contenido. Para generar esas recomendaciones, parte de los datos puede procesarse con un servicio de inteligencia artificial (Claude API de Anthropic). Los datos no se venden ni se comparten con nadie más ni se usan para publicidad.

Cómo quitar el permiso. Puedes revocar el acceso cuando quieras en https://myaccount.google.com/connections. Al revocarlo se dejan de recibir datos y los ya guardados se borran si lo pides.

Esta herramienta usa los Servicios de API de YouTube. Al usarla aceptas las Condiciones del Servicio de YouTube, y se aplica la Política de Privacidad de Google.

English

What it is. HanDy Analitica is a private tool of the HanDy YouTube channel team. It analyzes the channel's own data to decide what videos to publish. It is not a public service and is not offered to third parties.

Data accessed. With your permission, and always read-only, it uses the YouTube API Services (YouTube Data API, YouTube Analytics API and YouTube Reporting API) to access the authorized channel's information: video list and metadata, statistics (views, watch time, retention, subscribers), estimated revenue and traffic sources. It does not access your email, passwords, messages or other Google services.

Use and storage. Data is stored only on the channel team's own computer and used only to analyze channel performance and produce content recommendations. To produce those recommendations, part of the data may be processed by an AI service (Anthropic's Claude API). Data is never sold, shared with anyone else, or used for advertising.

Revoking access. You can revoke access at any time at https://myaccount.google.com/connections. After revocation no more data is received, and stored data is deleted on request.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.
